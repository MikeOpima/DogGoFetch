# 🐕 DogGoFetch Warehouse Management System

DogGoFetch is a lightweight **Warehouse Management System (WMS)**
designed to help businesses manage inventory and products

The system helps warehouse staff track stock levels, process orders, and
maintain accurate product records using a simple and user‑friendly
interface.

------------------------------------------------------------------------

# 📦 Features

-   Inventory tracking and stock monitoring
-   Product management (add, edit, delete products)
-   Track incoming orders.
-   Search and filter products quickly
-   Automatic inventory updates after transactions
-   Simple dashboard for warehouse staff

# 👤 System Actors

## Warehouse Staff / User

-   Add and update product information
-   Monitor inventory levels

## System

-   Stores product and inventory data
-   Updates inventory automatically
-   Maintains order history

# ⚙️ Installation

## 1. Clone the repository

    git clone https://github.com/MikeOpima/DogGoFetch



## 2. Create the database

1.  Open **phpMyAdmin**
2.  Create database:


    username_java

3.  Import the SQL file located in:


    database/doggofetch.sql

## 3. Start your server

Start:

-   SCWEB
